# Shopee Affiliate Mobile Analyzer

Host tinh cho bookmarklet phan tich Shopee Affiliate tren Chrome mobile.

## Bat GitHub Pages

1. Tao repository public tren GitHub.
2. Upload cac file trong thu muc nay len nhanh `main`.
3. Vao `Settings` -> `Pages`.
4. Chon `Deploy from a branch`.
5. Chon branch `main`, folder `/root`, bam `Save`.
6. Mo URL dang `https://USERNAME.github.io/REPO/`.

## Cach dung

1. Mo URL GitHub Pages tren dien thoai.
2. Copy bookmarklet trong o tren trang.
3. Tao bookmark trong Chrome va dan bookmarklet vao o URL.
4. Mo `https://affiliate.shopee.vn`, dang nhap Shopee Affiliate.
5. Go ten bookmark tren thanh dia chi va chon bookmark do.

Script chi tai file JS tu GitHub Pages va goi API cua `affiliate.shopee.vn` bang phien dang nhap hien tai.
